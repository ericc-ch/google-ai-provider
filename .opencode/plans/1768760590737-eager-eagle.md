# Plan: Remove Stale Package References from Examples and Update Package Dependencies

## Problem

1. The pnpm workspace installation fails because examples reference packages that don't exist in this workspace
2. Both `@ai-sdk/google` and `@ai-sdk/anthropic` packages have `workspace:*` dependencies on packages that don't exist locally

## Root Cause

This is a Google provider-specific monorepo containing only:

- `@ai-sdk/google` (packages/google)
- `@ai-sdk/anthropic` (packages/anthropic)
- `@vercel/ai-tsconfig` (tools/tsconfig) - THIS EXISTS
- `eslint-config-vercel-ai` (tools/eslint-config) - THIS EXISTS

Packages that are referenced but don't exist:

- `@ai-sdk/provider` - not in this workspace, needs to use published npm version (^2.0.1)
- `@ai-sdk/provider-utils` - not in this workspace, needs to use published npm version (^3.0.20)
- `@ai-sdk/test-server` - not in this workspace, needs to use published npm version (^1.0.1)

All examples were copied from the main Vercel AI SDK repository and reference core packages and other provider packages that exist in the main repo but not here.
